## Featured Projects

### 📡 WiFi CSMA/CA Performance & Security Study
[![Repo](https://img.shields.io/badge/Repository-CSMA--CA-181717?style=flat&logo=github)](https://github.com/Yousuf7788/CSMA-CA)
![C++](https://img.shields.io/badge/C++-00599C?style=flat&logo=cplusplus&logoColor=white)
![NS-3](https://img.shields.io/badge/NS--3-0078D4?style=flat&logo=buffer&logoColor=white)

A comprehensive NS-3 simulation framework for analyzing **IEEE 802.11g WiFi CSMA/CA** performance under varying network conditions — from baseline traffic to adversarial **rogue-STA flood attacks** — with and without **RTS/CTS** protection.

- Simulates 5+ legitimate stations with configurable traffic patterns
- Models rogue station injection attacks with high-rate flood traffic
- Measures throughput, end-to-end delay, packet delivery ratio, and Jain's Fairness Index
- Automated experiment scripts with CSV data export for analysis

### 🤖 Autonomous Wall Detection & Navigation System
[![Repo](https://img.shields.io/badge/Repository-MCI__Project__sp25-181717?style=flat&logo=github)](https://github.com/Yousuf7788/MCI_Project_sp25)
![C++](https://img.shields.io/badge/C++-00599C?style=flat&logo=cplusplus&logoColor=white)
![TI Tiva C](https://img.shields.io/badge/TM4C123GH6PM-CC0000?style=flat&logo=texasinstruments&logoColor=white)

An embedded systems project on the **TI Tiva C Series** microcontroller implementing autonomous robot navigation with real-time wall detection and obstacle avoidance.

- PD-like control logic for maintaining constant wall distance
- 3× HC-SR04 ultrasonic sensors (front, left, right) for environment mapping
- DC motor PWM speed control with directional steering
- Bluetooth (HC-06) remote command interface via UART
- Modular driver-based architecture for maintainability
